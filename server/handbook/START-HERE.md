# Nikita operator handbook

For the person maintaining this installation and their maintenance agent. Open just the note matching the task. These are release instructions, not live settings, credentials, permission to act, or text to inject into conversations.

| I want to… | Read |
| --- | --- |
| Recover the voice name, provider, free-tier check or enrollment procedure | [Speak: Google Gacrux](voice-output.md) |
| Understand a Russian microphone note or speech file without cloud transcription | [Listen: local GigaAM](voice-input.md) |
| Connect the Telegram account, select a chat, or check why Nikita is silent | [Telegram enrollment and admission](telegram.md) |
| Change the software and ship a reproducible update | [Maintainer release path](changes.md) |

Start with the installed version and a read-only check. Before any account change, use the owner's authorization for this instance. Never record API keys, session files, private links, prompts or message history in these notes. Keep deployment-specific recovery material in a separate private owner backup; the handbook is not that backup.
