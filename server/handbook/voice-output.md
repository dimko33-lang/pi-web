# Speak: the reference voice is Gacrux

Recovery card: **Google Gemini Developer API** (key from Google AI Studio) → **`gemini-3.1-flash-tts-preview`** → **`Gacrux`**. This is the mature Russian-speaking voice selected for Nikita, not Google Cloud Chirp, Qwen, local Irina or the incoming speech recognizer. **Approved preset: `gacrux-C-v1` (audition 3, no audible smile).** Use the installed `telegram/gacrux_worker.py`; release `v0.10.3` is the original reference for the voice request, not a reason to downgrade the worker's input limit. It requests an ordinary conversation in the comfortable middle register, a quiet beat before the last clause, no coaxing and no performed disdain. Do not add a breathiness cue: the chosen recording did not use one. `tests/spoken-reply.py` checks the canonical request against the audition fingerprint; the provider may still vary timing, breathing and timbre across generations. The original WAV is a private listening reference and is not part of the release. Phrasing belongs to the conversation's Response style; private profile settings are not shipped. This guides synthesis; it is not a fixed pitch shift. The conversation model writes the answer; the voice model reads it. Code: `telegram/gacrux_worker.py`.

1. **Check before installing.** On the host, identify the actual Telegram venv and service user. The optional per-venv `pi-web-gacrux-<id>.socket` is installed by `telegram/install-gacrux.py`. `systemctl list-sockets --all 'pi-web-gacrux-*'` checks for the broker without reading its key. An owner DM `/voice_all status` reports the *global default*, not provider health or a profile override. If already enrolled, start at step 4. Selecting Gacrux in a browser demo is not API enrollment.
2. **Verify cost for this particular project.** In [AI Studio → API Keys](https://aistudio.google.com/api-keys), match the key's project and look under **Billing tier**. Check the [model's Standard pricing table](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-tts-preview) and [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits). At publication the Free Tier lists both text input and audio output as free of charge. That is a quota-limited tier, not a promise about availability, unlimited usage or future pricing. Preview models can change. Google marks free-tier content as used to improve its products: even the short answer can be sensitive. Do not enable billing or enroll a paid project without separate approval.
3. **Enroll only if needed.** On standard root/systemd Linux, run as root: `python3 /root/PiWebRuntime/app/telegram/install-gacrux.py --venv /root/PiWebRuntime/telegram-venv --user root`. For other supported systemd layouts use the real installed script, venv and Telegram service user. Enter the key in the hidden prompt, never in a command argument, transcript or release. The broker gets a systemd credential; no shared Google key ships with Nikita.
4. **Choose the scope.** On the target `/profiles` tab, save **Voice** alone for spoken replies, **Text** alone for text, both to match a new microphone note vs a typed message, or neither to inherit. With neither selected, `Поговори со мной` asks for one cloud reply (Gacrux after enrollment, otherwise the public Qwen demo). `/voice_all on` in the enrolled owner's DM changes the instance default for *all* admitted conversations; do not use it to test one chat. `/voice_all off` restores on-request behavior where no profile override is set.
5. On builds with **Voice preset**, an individual DM can save **Charon · Quiet elder** for a measured, unsmiling male voice. **Gacrux** restores the reference sound. This setting changes synthesis only; the profile's Text/Voice switches still decide when to speak. A new enrollment installs the matching worker. To update only a previously enrolled broker after installing the new app code, run the original `telegram/install-gacrux.py --venv … --user …` command with `--refresh-worker`. It does not read the key, change billing or sign into Telegram. A legacy broker rejects an unsupported preset and leaves the answer as text rather than speaking it in the wrong voice.
6. **Verify the actual path.** Ask the owner to request a short non-confidential reply in an admitted chat. Expect a native Telegram voice note. Only the final answer (up to 1,500 characters for Gacrux; longer answers stay text and are never split into speech requests) is submitted for synthesis, not the incoming recording or entire conversation. Failure, long text and code can return text instead. Check the selected profile, broker and project quota before touching the key. No automatic paid upgrade or alternate voice after a Gacrux failure.
