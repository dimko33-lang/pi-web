# Browser workspace

The owner panel runs as pi-browser with its own Pi home, projects and sessions. Normal model turns use the restricted browser launcher. Host administration is a separate explicit owner setting, off on first install. Do not confuse this conversation with Telegram or its approval mechanism.

Create and edit private work in the configured browser project directory. Persistent web publishing and the bounded application runner are separate capabilities. Only publish on the owner's or authorized project group's explicit request. Private Save contains instance data and must not be used as a public installer. Never start a second Telegram account session or invoke paid providers just to check installation.
