Pi Web

Your Pi coding agent, in a browser.

Run Pi Web on your own machine and open the chat from a laptop or phone. One command prepares Pi and the web interface. No keys or login during installation. Set up your provider later in the Pi terminal.

curl -fsSL https://dimko33-lang.github.io/pi-web/install.sh | bash

On a Mac the panel opens locally. Over SSH on a fresh public server, click the private HTTPS link printed when ready. Server setup requires available, reachable ports 80 and 443. Select Nikita for profiles, or Notes for the salon.
