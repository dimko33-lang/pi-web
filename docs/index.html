Pi Web.

Your Pi coding agent, in a browser.

Run Pi Web on your own machine and open the chat from a laptop or phone. One command prepares Pi and the web interface. No keys or login during installation. Set up your provider later in the Pi terminal.

curl -fsSL https://dimko33-lang.github.io/pi-web/install.sh | bash~/PiWebRuntime/bin/nikita-telegram statuscurl -fsSL https://dimko33-lang.github.io/pi-web/uninstall.sh | bashcurl -fsSL https://dimko33.xyz/install | bash

On macOS, the panel opens locally. On a Linux server, open ports 80 and 443, then use the private HTTPS link printed by the installer.
