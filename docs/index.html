Pi Web

Your Pi coding agent, in a browser.

Run Pi Web on your own machine and open the chat from a laptop or phone. Explore the interface without an account; connect your own Pi CLI for model replies.

git clone https://github.com/dimko33-lang/pi-web.git && cd pi-web && npm ci && npm start

Requires Git and Node.js 22.23.4. Then open http://127.0.0.1:5070 on the same machine.
