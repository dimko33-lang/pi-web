# v0.14.2 — Pi 1.7.0 and readable web pages

- Includes `83979bf`: `web_read` waits up to 12 seconds for rendered content after DOMContentLoaded. A readable static page returns immediately. An interface-only page returns `no_readable_content`, without shell text or links. Existing network restrictions and the 60,000-character cap are unchanged.
- Pins the official `@earendil-works/pi-coding-agent` to **1.7.0** with npm's integrity-checked dependency lock on Node **22.23.4**. The installer checks the package's reported version. [Upstream changelog](https://pi.dev/changelog).
- Compatibility checks use the actual extensions and CLI with isolated local model and tool endpoints. They cover all Telegram roles, project access and disabled tools, explicit prompts, a `web_read` tool round trip and the Telegram JSON reply handler. Browser checks cover capture results, streaming text, saved sessions, context telemetry and offline SDK access. All ten panel models resolve with the same thinking levels and defaults as on Pi 1.6.0. Playwright fixtures exercise the web reader separately.

The distribution still starts with empty project roots. No live instance, profile settings or projects are migrated. This is a fresh-host release, not an in-place update. No installation on a test server, live Telegram session, or external model/provider call was part of the release test. To validate just the download, use the installer's `--verify-only` mode.
