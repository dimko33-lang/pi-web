# v0.13.0 — One conversation, three ways to reply

In an explicitly enabled Telegram group, type **Никита, …** for the profile's usual delivery, **Ника, …** for a Gacrux voice note, or **Ники, …** for a round video reply. Only a leading name selects a format; the model can decline third-person discussion. `/circle <request>`, `Кружок: <request>` and `ответь кружком: <request>` explicitly request video. These are application conventions, not built-in Telegram commands. Ordinary chats, private conversations and LightCone recovery do not inherit the demo route.

**Same assistant, same voice.** The normal group turn runs first. Gacrux synthesizes the answer once. Only then does the optional isolated Anam worker receive the prepared 24 kHz mono audio and animate your chosen compatible avatar. The session uses Cara 4.1 Express, passthrough and restrained direction. The return audio is checked near both speech boundaries, and the square H.264/AAC file is checked against Telegram's one-minute cap. The transport requests and verifies a native video note replying in the same group. A preparation failure falls back to text; uncertain Telegram sends are checked, not retried. Avatar expression and lip sync are model-dependent, not per-gesture controls.

**Also included since v0.12.1:** an individual DM can choose the Gacrux or Charon Google speaker independently of text/voice delivery. Group context can refer back to one eligible earlier photo on demand, with the current peer, history window and media protections rechecked before download; it does not maintain a persistent pixel gallery.

## Enable on a new installation (optional)

1. Install Telegram and enroll the existing Gacrux broker as described in [the usage guide](../usage.md). Obtain your own Anam API key and a compatible avatar ID from Anam Lab. No key, avatar, Telegram session or group permission is included in this release. The ordinary card install does not contact Anam.
2. On a Linux/systemd host with Python 3.12 and venv support, from a trusted release directory run `sudo bash telegram/install-circle.sh TELEGRAM_VENV SERVICE_USER AVATAR_UUID`, replacing the three placeholders. Use the same venv and OS user as Gacrux; enter the Anam key at the hidden prompt. The worker has a separate environment and loads the secret via systemd. The installer refuses to overwrite an existing broker.
3. As the instance user, using the same instance environment as the Telegram worker, run `TELEGRAM_VENV/bin/python telegram/instance.py bind piwep NEGATIVE_CHAT_ID --replies --circles`. Use the actual group ID and its matching bound tab. A tab cannot be silently rebound to another peer. `--no-circles` disables these format shortcuts without disabling ordinary replies. An archive-only binding grants no permission to reply.
4. In the group, try `Ники, скажи пару слов`. Any participant of an enabled group can use it and consume your provider allowance. One Anam session per socket, no automatic purchase or top-up by Pi Web. Audio and video are temporary; the text of a confirmed note is stored with the outgoing peer and message ID. The standard installer is not an in-place server upgrade.

The live demo owner tested all three variants. Portable group routing is tested with synthetic peers; use your own credentials for a live end-to-end deployment. Alternative video providers are not part of this release.
