# v0.14.1 — Environment, not instance content

Fresh Ubuntu installs start with empty application and publishing roots. The bounded project runner, dependency proxy, candidate health checks, publish/withdraw/rollback and private Save remain. The sandbox toolchain is built without copying any user's application into the image. Group profiles require explicit peer input. This is a new release, not an update or cleanup script for existing machines.

A pre-release build installed on a disposable Ubuntu 24.04 x86-64 VM (two CPUs, self-signed test TLS, no host directory mounts). The initial app host returned 404. A synthetic app was created via the real broker, checked, published twice, rolled back and withdrawn. Both static roots served synthetic files. Authenticated private Save returned the working source, saved releases, mutable data, test article, browser file and snapshot marker. After a reboot the mounted workspace, selected release, public response and profile-catalog checksum survived. A repeat installation check left those files intact. The final toolchain image also passed a real candidate check. Local package, role and authenticated panel/entry checks used synthetic inputs. This is not a test of public ACME, live Telegram, paid providers or full disaster recovery. Older releases, tags and Git history are not changed by this version.
