## Pi Web v0.14.0 — Ubuntu reference installer

**Чистая установка на Ubuntu 24.04 ещё не проверена.** A clean Ubuntu install, reboot and end-to-end Telegram/provider delivery have not yet been tested. Snapshot a fresh test machine before running this release; it is not an upgrade for an existing host.

This release packages the actual reference panel, site entry, Telegram role tools, profile/memory handlers, readers, Salon, media/PDF/voice and circle workers, science, CurveLab, nginx routes and systemd services. The installer targets Ubuntu Server 24.04 x86-64. It provisions the isolated workspaces, locked runtimes, project volume, Docker images, fresh credentials and HTTPS. The panel's Save action still uses the private backup handler, not a source exporter.

The release contains application code, not an enrolled identity. No Telegram session, private profile store, provider authorization, conversation database, private portrait or original binding file is distributed. Telegram and its collectors stay off until explicitly enrolled. No keys or model logins are required to run the installer; provider-dependent actions need your own credentials afterward.

Local checks cover the 372-file reference payload and 10 declared links, rendered configuration and roles, plus the real panel and site-entry HTTP login with fresh synthetic settings. They do not prove Linux installation or functional parity under load. No changes were installed on the working or test server for this release.
